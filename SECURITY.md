# Security policy

## Reporting a vulnerability

Email support@looot.ai with "looot security" in the subject.

Please do not open a public issue for a vulnerability. Include the affected component (the hosted server at `https://api.looot.ai/mcp`, the npm bridge in this repo, or the docs), steps to reproduce and the impact you saw.

We reply within 3 working days and tell you when a fix ships.

## Scope

- The local stdio bridge and scripts in this repository.
- The hosted MCP server at `https://api.looot.ai/mcp` and its OAuth sign-in.

## Supported versions

Only the latest published version of the `looot-mcp` npm package gets fixes.
